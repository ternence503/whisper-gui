# Mac 新手包（Whisper_Mac_一鍵安裝版）

這個資料夾是給 Mac 新手用的「一鍵安裝 + 一鍵啟動」版本。

## 署名資訊

- 作者：Ternence
- 版本：v1.3.0


## 使用步驟（給新手）

1. 把整個 `Whisper_Mac_一鍵安裝版` 資料夾複製到自己的 Mac（例如桌面）。
2. 雙擊 `▶ 啟動 Whisper.command`。
3. 第一次會自動完成：
   - 安裝 Homebrew（若尚未安裝）
   - 安裝 Python 與 ffmpeg
   - 建立本地虛擬環境
   - 安裝 Whisper 套件
   - 下載 Whisper 模型（預設 `small`）
4. 完成後會自動開啟圖形介面。
5. 之後一樣雙擊 `▶ 啟動 Whisper.command` 即可（已安裝會直接開啟）。
6. 提示：把 `▶ 啟動 Whisper.command` 拖到 Dock，以後就像一般 App 一鍵啟動。
7. 可直接選擇音檔或影片（例如 mp3/wav/mp4/mov/mkv），程式會自動轉成文字。
8. 也可切到「文字轉語音」分頁，貼上文字輸出 MP3。
9. 中文內容會自動轉為繁體；外語內容維持原文輸出。
10. 「歌詞辨識」分頁：選擇音樂檔，可選擇先用 Demucs 分離人聲（去除背景音樂、提升辨識準確率，首次使用會額外下載約 80MB 模型），辨識後輸出純歌詞 `.txt`、帶時間戳的 `.lrc`、字幕 `.srt`。

## 更新（既有使用者）

重新下載最新版 zip，雙擊 `▶ 啟動 Whisper.command`，程式會自動偵測新版本並更新，無需手動操作。

## 發佈前清理（建議）

如果你要把這包傳給別人，先雙擊：

- `99-打包前清理.command`

用途：
- 清掉 `.venv`、模型、快取與 macOS 暫存檔
- 降低檔案體積
- 避免把你本機暫存一起打包出去

## 第一次使用可能看到的提示

- macOS 可能會提示「不明開發者」，請到：
  - 系統設定 -> 隱私權與安全性 -> 允許執行
- 第一次安裝 Homebrew 時，可能要求輸入 Mac 登入密碼。

## 系統需求

- 建議 macOS 12 以上
- 第一次安裝需連網

## 輸出檔案

轉錄後會在原檔案同資料夾產生：

- `原檔名_語言代碼.txt`
- `原檔名_語言代碼.srt`
- `原檔名_語言代碼.vtt`

歌詞辨識會在原檔案同資料夾產生：

- `原檔名_lyrics_語言代碼.txt`
- `原檔名_lyrics_語言代碼.lrc`
- `原檔名_lyrics_語言代碼.srt`

文字轉語音會輸出 `.mp3`，支援 12 種聲音：

**台灣腔**
- 台灣女聲・活潑、台灣女聲・清亮、台灣男聲・沉穩

**粵語腔**
- 粵語女聲・活潑、粵語女聲・溫柔、粵語男聲・友善

**普通話**
- 普通話女聲・活潑、普通話女聲・溫柔
- 普通話男聲・熱情、普通話男聲・陽光、普通話男聲・穩重、普通話男聲・可愛

輸出模式：原文直出、2 分鐘精簡版、短影音版

注意：文字轉語音每次使用都需要網路連線（使用 Microsoft Edge TTS 雲端服務）。

## 進階（可選）

若第一次想改模型，可在終端機進入此資料夾後執行：

```bash
./_internal/setup_and_run_mac.sh medium
```

或：

```bash
./_internal/setup_and_run_mac.sh turbo
```
