# Windows 新手包（Whisper_Windows_一鍵安裝版）

這個資料夾是給 Windows 入門者使用，目標是「一鍵安裝、一鍵啟動」。

## 署名資訊

- 作者：Ternence
- 版本：v1.2.0


## 使用者怎麼操作

1. 把整個 `Whisper_Windows_一鍵安裝版` 資料夾複製到 Windows（例如桌面 `WhisperWin`）。
2. 雙擊 `01-install-and-run.bat`。
3. 第一次會自動完成：
   - Python 環境建立
   - 套件安裝
   - FFmpeg 下載
   - Whisper 模型下載（預設 `small`）
4. 安裝完會自動開啟 GUI。
5. 之後直接雙擊 `02-start-app.bat` 即可啟動。
6. 可直接選擇音檔或影片（例如 mp3/wav/mp4/mov/mkv），程式會自動轉成文字。
7. 也可切到「文字轉語音」分頁，貼上文字輸出 MP3。
8. 中文內容會自動轉為繁體；外語內容維持原文輸出。

## 更新（既有使用者）

只需覆蓋 GUI 程式檔，不需重新安裝環境：

1. 下載新版 `whisper_gui_win.py`
2. 覆蓋原本資料夾內的同名檔案
3. 雙擊 `02-start-app.bat` 即可

## 發佈前清理（建議）

如果你要把這包傳給別人，先雙擊：

- `99-打包前清理.bat`

用途：
- 清掉 `.venv`、模型、ffmpeg 與快取暫存
- 降低檔案體積
- 避免把你本機狀態一起打包出去

## 第一次安裝需求

- 需要網路（只要第一次）。
- 建議 Windows 10/11 64 位元。

## 要打包給別人時注意

- 這個 `Whisper_Windows_一鍵安裝版` 資料夾內的檔案請保持完整，不要拆開。
- 不要改名 `setup_and_run.ps1`、`whisper_gui_win.py`。
- 若第一次想改模型，可在命令列執行：
  - `01-install-and-run.bat medium`
  - `01-install-and-run.bat turbo`

## 轉錄輸出

輸出會存在原檔案同一個資料夾：

- `檔名_語言代碼.txt`
- `檔名_語言代碼.srt`
- `檔名_語言代碼.vtt`

文字轉語音會輸出 `.mp3`，支援 12 種聲音：

**台灣腔**
- 台灣女聲・活潑、台灣女聲・清亮、台灣男聲・沉穩

**粵語腔**
- 粵語女聲・活潑、粵語女聲・溫柔、粵語男聲・友善

**普通話**
- 普通話女聲・活潑、普通話女聲・溫柔
- 普通話男聲・熱情、普通話男聲・陽光、普通話男聲・穩重、普通話男聲・可愛

輸出模式：原文直出、2 分鐘精簡版、短影音版

注意：文字轉語音每次使用都需要網路連線（使用 Microsoft Edge TTS 雲端服務）。
