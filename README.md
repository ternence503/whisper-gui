# Whisper 語音工具

本地執行的語音工具，附圖形介面，小白也能輕鬆使用。
作者：Ternence｜版本：v1.2.0

---

## 功能

### 語音轉字幕（完全離線）
- 支援 mp3、wav、m4a、aac、flac、mp4、mov、mkv 等常見格式
- 自動偵測語言；中文內容自動轉為繁體
- 輸出 `.txt`、`.srt`、`.vtt` 三種格式
- 純 CPU 執行，不需 GPU
- 模型下載一次後，之後不需網路

### 文字轉語音（需網路）
- 12 種聲音，分為三組：
  - **台灣腔**：活潑、清亮、沉穩（男）
  - **粵語腔**：活潑、溫柔（女）、友善（男）
  - **普通話**：活潑、溫柔（女）、熱情、陽光、穩重、可愛（男）
- 語速 / 音高可調
- 輸出模式：原文直出、2 分鐘精簡版、短影音版
- 朗讀優化：時間、電話、網址自動轉為口語形式
- 輸出 `.mp3`，長文自動分段合成後合併

## 下載與安裝

### Mac 使用者

1. 下載 `Whisper_Mac_一鍵安裝版` 資料夾
2. 雙擊 `01-一鍵安裝並啟動.command`
3. 第一次會自動安裝環境並下載模型（需連網）
4. 之後只要雙擊 `02-直接啟動.command` 即可

> macOS 可能提示「不明開發者」，請至「系統設定 → 隱私權與安全性 → 允許執行」

### Windows 使用者

1. 下載 `Whisper_Windows_一鍵安裝版` 資料夾
2. 雙擊 `01-install-and-run.bat`
3. 第一次會自動安裝環境並下載模型（需連網）
4. 之後只要雙擊 `02-start-app.bat` 即可

## Whisper 模型說明

| 模型 | 大小 | 速度 | 精度 |
|------|------|------|------|
| base | ~150 MB | 最快 | 較低 |
| small | ~490 MB | 快（預設）| 中 |
| medium | ~1.5 GB | 中 | 高 |
| large | ~3 GB | 慢 | 最高 |
| turbo | ~1.6 GB | 快 | 接近 large |

**Windows**

- 第一次安裝需連網

## 注意事項

- **語音轉字幕**：模型下載後完全離線執行
- **文字轉語音**：每次合成都需要網路（使用 Microsoft Edge TTS 雲端服務）
