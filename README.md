# Whisper 語音轉字幕工具

本地離線執行的 Whisper 語音轉字幕工具，附圖形介面，小白也能輕鬆使用。

- 支援 mp3、wav、m4a、mp4、mov、mkv 等常見格式
- 自動偵測語言；中文內容自動轉為繁體
- 輸出 `.txt`、`.srt`、`.vtt` 三種格式
- 純 CPU 執行，不需 GPU
- **完全離線**：模型下載一次後，之後不需網路

作者：Ternence｜版本：v1.1.0

---

## 下載與使用

### Mac 使用者

1. 下載 `Whisper_Mac_一鍵安裝版` 資料夾（或 Clone 整個 repo）
2. 雙擊 `01-一鍵安裝並啟動.command`
3. 第一次會自動安裝環境並下載模型（需連網）
4. 之後只要雙擊 `02-直接啟動.command` 即可離線使用

> macOS 可能提示「不明開發者」，請至「系統設定 → 隱私權與安全性 → 允許執行」

### Windows 使用者

1. 下載 `Whisper_Windows_一鍵安裝版` 資料夾（或 Clone 整個 repo）
2. 雙擊 `01-install-and-run.bat`
3. 第一次會自動安裝環境並下載模型（需連網）
4. 之後只要雙擊 `02-start-app.bat` 即可離線使用

## 模型說明

| 模型 | 大小 | 速度 | 精度 |
|------|------|------|------|
| base | ~150 MB | 最快 | 較低 |
| small | ~490 MB | 快（預設） | 中 |
| medium | ~1.5 GB | 中 | 高 |
| large | ~3 GB | 慢 | 最高 |
| turbo | ~1.6 GB | 快 | 接近 large |

預設使用 `small` 模型，兼顧速度與精度。如需更高精度，可在 GUI 的模型選單中切換。

## 系統需求

**Mac**
- macOS 12 以上
- 第一次安裝需連網

**Windows**
- **Windows 10 以上**（不支援 Windows 7 / 8 / 8.1）
- Python 3.9+（首次安裝時若未安裝，會自動透過 winget 安裝）
- 第一次安裝需連網
